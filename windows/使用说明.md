# Windows 使用说明

## 更新和启动

1. 解压新版到新文件夹。停止旧版班讯后，把旧项目的 `.env` 和 `data` 文件夹复制到新版根目录。
2. 双击 `windows/Start-All.cmd`。首次启动需要 Python 3.12 或更新版本，并联网安装依赖。后续会复用 `.venv-windows`。
3. 在打开的 NapCat WebUI 侧边栏选择 **班讯 · 核对与日程**。如果插件首次安装后没显示，退出并重新启动 NapCat 一次，再运行统一入口。
4. 用本机 `.env` 的 `APP_TOKEN` 登录班讯。需要退出班讯时，在它的运行窗口按 Ctrl+C。

NapCat 放在其他位置时，在 `.env` 加 `NAPCAT_HOME=你的安装目录`，填写包含 `napcat.mjs` 的文件夹。启动器读取 NapCat 的 WebUI 配置端口，默认 6099。端口被占用、或 NapCat 使用了不同的实际端口时，在 `.env` 填写 `NAPCAT_WEBUI_PORT=实际端口`。班讯默认地址是 http://127.0.0.1:8080/assistant/ 。只需使用班讯时，可双击 `windows/Start-Native.cmd`。

## 群聊与核对

- 已连接的账号可继续沿用原来的 OneBot 设置。首次配置时，将 `GROUP_WHITELIST` 填为目标群号，多个群用英文逗号隔开。NapCat 的反向 WebSocket 默认填 `ws://127.0.0.1:8080/onebot/v11/ws`，Token 使用 `.env` 的 `ONEBOT_ACCESS_TOKEN`。
- 在 **数据与连接** 核对群成员状态后，可读取最近历史，或从已入库的最早消息继续向前翻。回补范围取决于 QQ 实际返回的消息。
- 在 **核对与整理** 查看来源和日期。确认后可加入日程。过去的比赛可以在 **通知日程 → 已截止 / 已结束** 查看。

截图 OCR 需要另装 Tesseract。Windows 一键启动和真实 QQ 登录仍需本机验证。更多设置见 [项目说明](../README.md)。
