# Windows 发布包验收

| 检查 | 验收结果 |
| --- | --- |
| 统一启动脚本 | Linux 上用 PowerShell 和本机模拟 WebUI 验证首次启动、重复启动、自定义端口、NapCat 或班讯端口占用、两次同时启动以及未安装 NapCat 的情况。 |
| 历史回补 | 单次 2,000 条成功；一次事务按发送顺序入库；重复读取新增 0 条。翻页中断和写库失败后可以重试。同一秒的消息可以继续向前回补。从 ZIP 全新解压后，也通过实际 OneBot 适配器和合成数据验证了 2,000 条回补、确认、日历导出及重启。 |
| 后端回归 | 36 项测试通过，覆盖同群、同账号的延期合并、旧数据读取、备份恢复及日历导出。 |
| Chromium | 通过模拟 WebUI 内嵌登录与确认流程。已结束比赛筛选、队列按需加载、页面详情及手机布局通过检查。 |
| OneBot | 通过合成 WebSocket 验证连接鉴权、群成员查询、群消息、断线和持久化。 |

在实际 Windows 上，双击 `windows\Start-All.cmd`，登录 NapCat 后打开侧栏的「班讯 · 核对与日程」。在「数据与连接」检查群成员状态，读取一批已知近期群消息，再从最早一条继续向前回补。Windows 一键启动、真实 NapCat 插件加载和 QQ 历史返回仍待实机核对。
